# 引言（中文完整对应稿）

精准量化膳食能量与常量营养素摄入是营养流行病学、人群代谢健康监测与慢性心血管代谢疾病护理的基石。在 1 型或需要胰岛素治疗的 2 型糖尿病患者中，精准的碳水化合物计数对于通过个体化胰岛素与碳水化合物比例计算餐时速效胰岛素大剂量至关重要。依据美国糖尿病协会设立的临床规范，平均份量餐食的碳水化合物估算误差超过 15\,g（或大约 20\% 的相对误差）将严重破坏餐后血糖平衡，诱发急性致死性低血糖或加速长期微血管与大血管并发症的持续餐后高血糖。尽管其具有明确的治疗必要性，但包括 24 小时膳食回顾、食物频率问卷和称重饮食日记在内的传统自述评估工具给患者带来沉重的认知负担，易受回忆疲劳影响，且对高热量食物普遍存在系统性少报现象。这些行为摩擦与测量偏差凸显了临床上对能够实现被动、实时量化的自动化、客观膳食监测技术的迫切需求。

为了克服自述式评估的固有局限，基于计算机视觉和深度神经网络的自动化膳食监测已成为数字健康与代谢医学的前沿方向。基于智能手机的膳食应用程序越来越多地采用卷积神经网络、视觉 Transformer 和多任务学习架构，直接从单张餐食照片中分割食物轮廓、推断三维份量体积，并估算热量和常量营养素含量。这些自动化系统展现出客观、实时营养追踪的临床前景，能够无缝集成到闭环人工胰腺系统、移动健康决策支持工具以及个性化代谢管理平台中。通过将患者负担简化为单次拍照记录，光学膳食评估系统有望显著提升患者对医学营养治疗的长期依从性，并深刻变革多元人群中的临床糖尿病自我管理模式。

尽管算法取得了快速发展，但支撑膳食计算机视觉的实证基准数据集绝大多数局限于西方企业食堂环境。最具代表性的开源基准 Nutrition5k 包含在北美机构食堂配餐线上组装的菜肴，其特点是平盘上排列着离散、未混合且视觉边界清晰的成分，如烤鸡排、清蒸西兰花和切片烤薯块。当仅在这些同质化基准上训练的模型被部署到多民族人群中时，它们遭遇了剧烈的文化领域漂移。在南亚和东亚饮食传统中，烹饪主要涉及复合咖喱、炖菜和浓汤，其中富含能量的豆类、磨碎的淀粉和烹饪油脂（如酥油或芥末油）分散在光学不透明的酱汁中。由于标准光学传感器仅能捕获二维表面反射光谱，这些不透明基质的内部密度无法仅凭外部视觉特征加以解析，从而形成了视觉不确定性。因此，基于西方食堂菜品训练的模型缺乏感知非西方复合餐食中隐藏营养素所需的内部密度表征。

这种跨文化差异因基准标签来源中未经解决的方法学差距而进一步加剧。西方基准通过准备前后的精密物理称重结合标准实验室成分数据库（如 USDA SR28）来确立真值，从而在人工机构环境中确保了极高的内部有效性。相反，非西方真实膳食基准（如南亚的 FoodBD）收集来自家庭餐桌的现场照片，其真值是由持证临床营养师使用与区域食物成分表相关联的传统体积器具估算的。迄今为止，营养人工智能领域的文献混淆了这些不同的标签来源体系，仅通过在随机打乱的交叉验证集上计算的对称性全局汇总指标（如决定系数和平均绝对误差）来评估模型。这种标准做法掩盖了方向性系统偏差，无法反映全局平均误差是否掩盖了少数族裔饮食传统中危及生命的、特定人群的碳水化合物低估。

这种未经审计的算法不平等构成了全球数字医学中不容忽视的临床安全与公平性隐患。在世界范围内，糖尿病不成比例地影响着南亚、东亚以及中低收入国家的人群，而这些地区的饮食习惯与西方机构食堂存在根本性差异。在这些地区部署未经校准的计算机视觉算法，面临着系统性低估碳水化合物负荷的严重风险，这会直接转化为餐时胰岛素注射剂量不足以及严重的餐后高血糖。尽管存在这些显而易见的风险，现行的数字健康技术报告指南和医疗器械监管审批框架往往缺乏针对跨文化验证和方向性安全审计的强制性要求。临床上亟需建立标准化的多队列评估协议，以明确量化方向性估算偏差、评估临床安全阈值，并深入解析驱动跨文化性能衰退的物理与生化机制。

为了应对这些基础性挑战，本研究建立了一个标准化的多队列跨文化评估协议与实证审计框架，涵盖三种不同的烹饪传统（共计 $N=3,823$ 张餐食图像）。我们在西方食堂菜肴（Nutrition5k，$N=506$）上训练了一个受 Atwater 生理能量守恒定律约束的多任务深度神经网络，并评估其向南亚复合餐食（FoodBD，$N=1,833$）和东亚离散食品（ECUSTFD，$N=1,484$）的零样本迁移表现。通过评估方向性系统偏差、Bland-Altman 医学一致性、Lin 一致性相关系数以及美国糖尿病协会临床安全阈值，我们发现南亚餐食中存在严重的碳水化合物负向系统偏差（$-18.18$\,g，$p = 8.64 \times 10^{-206}$），导致临床安全合规率崩溃至 $49.48\%$。正交误差分解表明，超过 $75\%$ 的跨文化误差源于内部营养密度的感知坍塌，而非几何份量质量的计算偏差；而仅需 $K=50$ 份标注餐食的就地极少样本重校准即可将临床安全合规率恢复至 $63.9\%$。本研究提供了一套切实可行的实证审计方案和监管蓝图，以消除算法不平等，确保全球数字营养系统的测量有效性与治疗安全性。
